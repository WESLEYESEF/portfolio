# 🎬 Buscador de Filmes

Aplicação web que busca filmes usando a API do **TMDB (The Movie Database)**.

## Funcionalidades
- Pesquisa de filmes por nome
- Exibe pôster, título, ano e nota (avaliação)
- Interface responsiva em português

## Tecnologias
- HTML, CSS e JavaScript puro (sem frameworks)
- API TMDB

## Como usar

1. Obtenha uma chave gratuita em [themoviedb.org](https://www.themoviedb.org/settings/api)
2. Abra o arquivo `script.js`
3. Troque `SUA_CHAVE_AQUI` pela sua chave
4. Abra o `index.html` no navegador (ou publique no GitHub Pages)
